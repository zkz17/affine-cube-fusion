# Data layout and naming conventions

All per-case files are **line-aligned with `test_cases/test_cases_{n}`**: line `i` of any
per-case file (line 1-based) refers to the truth table given on line `i` of the test-case
file. Each per-case line has the form `tt:value`, where `tt` is the truth-table integer and
`value` the per-case number (a T or CX cost, or a lower bound).

## Directory overview

```
data/
  test_cases/        test_cases_{n}: one truth-table integer per line (random sample per n)
  exorcism_cost/     exorcism_{t,cx}_cost_{n}: Exorcism baseline T/CX cost per case
                     exorcism_time_11: Exorcism runtime on n=11
  sshr_cost/         sshr_{t,cx}_cost_{n}: SSHR baseline T/CX cost per case (n=3..6 only;
                     the n≥7 files exist but are empty), sshr_time_{n}
  our_cost/
    t_cost/          our_t_cost_{tag}_{n}_{start}_{stop}.txt   (per-case T cost, default runs)
    cx_cost/         our_cx_cost_{tag}_{n}_{start}_{stop}.txt  (per-case CX cost, default runs)
    deg_bound/       deg_bound_{n}_{start}_{stop}.txt          (G-3 lower bound t(deg f); shared by
                     all paths -- identical for every path and M2 setting at the same n)
    our_results_{tag}_{n}_{start}_{stop}.txt                   (per-run summary: avg synthesize wall,
                     Exorcism/SSHR comparison blocks, G-3 bound line)
    no_M2/           the same per-case t_cost/cx_cost files for the m2_post=False runs, with
                     the tag suffix `_noM2`, plus their our_results summaries
    no_M2_vs_default.txt   (per-case M2-vs-noM2 comparison, generated by data/compare_no_m2.py)
  compare_no_m2.py   script comparing no_M2/ runs against the default runs
```

## Naming rules

- `tag` is one of:
  - `A`  BDD path (`paths=A`)
  - `C`  ANF path (`paths=C`)
  - `F`  FPRM path (`paths=F`, the production default)
  - `FP` FPRM path with the proxy prescreen (`paths=F`, `proxy=1`)
  - `G`  GL(n,2) local search (`gl=1`)
- `n` is the number of variables; `start`/`stop` are the case range taken from
  `test_cases_{n}` (inclusive start, exclusive stop).
- Default runs are produced with the macro-M2 post-processing **on** (`m2=1`, plain tag);
  comparison runs with it **off** (`m2=0`) carry the `_noM2` tag suffix and live under
  `data/our_cost/no_M2/`.
- The G-3 lower bound `t(deg f)` depends only on `(n, tt)`, so exactly one
  `deg_bound_{n}_{start}_{stop}.txt` is kept per n (covering the largest available range).

## Reproducing a run

```bash
python evaluate.py <n> 1 0 <start> <stop> <gl> <proxy> <paths> [m2]
#  gl=1 selects G; proxy=1 with paths=F selects FP; m2=0 produces the _noM2 comparison runs
```

## Comparing M2 vs no-M2

```bash
python data/compare_no_m2.py
#  emits data/our_cost/no_M2_vs_default.txt: per-case lower/higher/same counts,
#  percentages and total costs of the default (M2-on) runs against the no_M2 runs,
#  matched by the `tt` key.
```
